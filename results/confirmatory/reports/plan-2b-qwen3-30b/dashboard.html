How these numbers are computed

Share of the evaluable runs whose answer lies within the tolerance of the computed reference; the bar is the 95 % interval, resampled over tasks. Runs that are not evaluable (HTTP 429 / API error) are never in a rate. Tool use: the prompt is the same in every condition, and whether a B run runs code or a C run calls the TS-MCP server is the model's choice; every run counts in its rate, and the tile splits the share correct by tool use.

Difference: mean over the tasks run under both conditions of the share correct under the first minus the share under the second, in percentage points (pp). Interval: percentile bootstrap with tasks resampled, 5000 draws. The last two columns count the tasks correct in most of their runs under one condition only.
